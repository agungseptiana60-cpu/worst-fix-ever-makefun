The worst fix ever, in one commit message: silence the smoke alarm by removing its battery, so the house can now burn quietly. The repair worked too well — it removed the warning the alarm exists to give. The program in `main.ts` writes that single line (87 characters, inside the 100-character gate) to `entry.txt` in the output directory, after checking the line against the gate itself.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
